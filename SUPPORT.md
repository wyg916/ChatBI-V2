# Support

## Where to ask

- Use a GitHub Discussion for usage questions, deployment guidance, and design proposals when Discussions are enabled.
- Use the bug report form for reproducible product defects.
- Use the feature request form for changes that serve the ChatBI core workflow.
- Use GitHub private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

## Information to include

Provide the ChatBI version or commit, operating system, Docker and database versions, deployment mode, the smallest reproducible steps, and sanitized logs. Never attach `.env`, API keys, database passwords, cookies, bearer tokens, private certificates, customer data, or full production query results.

## Support boundary

The project provides community best-effort support. The source release is suitable for local deployment, Enterprise PoC, private-deployment validation, and secondary development; it is not a production certification or an SLA-backed service. Provider availability, billing, quotas, and data policies remain the operator's responsibility.
