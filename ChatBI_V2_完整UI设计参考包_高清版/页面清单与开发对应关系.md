- 设计基准：1440×900
- 高清输出：2880×1800（2×）
- 一级导航：问数据、数据源、语义模型、答案库、看板、评测中心
- 系统设置：模型服务、用户、角色和审计

## 开发使用规则

1. 以单页 PNG 为视觉基准，以同名 HTML 为结构和间距参考。
2. 浏览器 100% 缩放、1440×900 基准下不得裁切核心内容。
3. 1366×768 保留核心操作，1920×1080 合理扩展内容宽度。
4. SQL 和执行细节默认折叠，不展示模型内部思维过程。
5. 问数据为登录后的默认首页，禁止改造成通用后台首页。
