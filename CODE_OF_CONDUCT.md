# Code of Conduct

ChatBI V2 welcomes contributions from people with different backgrounds and levels of experience. Participation in the project requires respectful, professional, and constructive behavior.

## Expected behavior

- Discuss ideas and code on their technical merits.
- Give actionable feedback and assume good intent.
- Respect privacy, security boundaries, licenses, and data ownership.
- Help newcomers understand the project without dismissive language.
- Disclose conflicts of interest that could affect a technical decision.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information or credentials.
- Deliberately weakening security, tenant isolation, result verification, or release gates.
- Repeated disruption, spam, or knowingly false technical claims.

## Reporting and enforcement

For ordinary conduct concerns, contact the maintainers through a private GitHub discussion with a repository owner. For security-sensitive reports, use the private vulnerability reporting channel described in [SECURITY.md](SECURITY.md). Do not place personal data, credentials, or exploitable vulnerability details in a public issue.

Maintainers may edit or remove contributions, issue a warning, temporarily restrict participation, or permanently ban a participant when necessary to protect the community and the project. Reports will be reviewed as privately and impartially as practical.

This policy applies to project repositories, issue trackers, pull requests, reviews, releases, and project-related community spaces.
