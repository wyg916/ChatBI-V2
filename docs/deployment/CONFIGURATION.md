# 配置

以根目录 `.env.example` 为配置字段清单。服务端读取 `.env`，显式进程变量优先。

- `CHATBI_DATABASE_URL`：PostgreSQL 元数据库连接。
- `COMPOSE_PROJECT_NAME`：部署实例名称。
- `CHATBI_FRONTEND_PORT`、`CHATBI_BACKEND_PORT`、`CHATBI_RAG_PORT`：服务端口。
- `CHATBI_DATASOURCE_SECRET_KEY`、`CHATBI_RAG_SHARED_SECRET`：由初始化脚本生成的服务端密钥。
- `CHATBI_BOOTSTRAP_ADMIN_PASSWORD`、`CHATBI_BOOTSTRAP_ANALYST_PASSWORD`：初始化登录密码。
- `CHATBI_STORAGE_ROOT`、`CHATBI_BACKUP_ROOT`：运行存储与备份路径。
- `CHATBI_EVALUATION_MANIFEST_PATH`：容器内已批准评测数据集路径。

模型与检索配置参见 [模型说明](../MODEL_PROVIDERS.md)。不向浏览器传递数据库或模型凭据。
