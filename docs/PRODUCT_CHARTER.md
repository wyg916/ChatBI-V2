# ChatBI V2 产品章程

## 一、产品目标

构建一个独立、可开源、可企业部署的 ChatBI 产品。产品核心是将自然语言问题稳定地转换为受语义层约束的只读查询，返回可验证的正确结果，并生成图表、业务洞察、标准答案和看板。

## 二、用户价值

- 业务人员无需编写 SQL 即可获得可信数据答案。
- 数据团队通过语义模型统一指标、维度、术语和关系口径。
- 管理人员可将问数结果沉淀为看板并持续跟踪。
- 工程团队可通过评测中心对模型、Prompt、语义模型和 SQL 引擎进行可重复回归。

## 三、成功标准

1. 本机 PostgreSQL/MySQL 完成一次初始化后，`scripts/start.ps1` 可启动完整应用环境；业务和元数据不保存到 Docker 数据卷。
2. PostgreSQL 作为主开发/主测试数据库，MySQL 作为辅助兼容数据库，两者均通过只读数据源账号同步 Schema。
3. 可建立并发布最小语义模型。
4. 用户可用自然语言完成查询、查看 SQL 依据、图表、明细和业务结论。
5. 可把正确答案保存到答案库并转成看板卡片。
6. Golden Set 可在 CI 中执行并形成发布门禁。
7. 所有核心能力属于本项目自有架构，第三方组件可替换且许可证清晰。

## 四、开发数据原则

- 当前没有企业数据时，按真实经营业务关系生成可复现模拟数据并写入本机数据库，不在前端写死业务数据。
- 前端通过 Backend API 使用真实数据库数据；浏览器不得直连数据库或持有数据库凭据。
- 项目元数据和主验证链路以本机 PostgreSQL 为准，MySQL 用于第二方言与连接兼容验证。

## 五、明确不做

首版不做通用 Agent 平台、复杂长期记忆、通用知识库生命周期、复杂告警平台、预测算法平台、插件市场和大而全的企业治理后台。
