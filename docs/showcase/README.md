## 录像只演示这 7 个功能

1. 登录后默认进入“问数据”的 Chat-first 产品入口。
2. PostgreSQL/MySQL 数据源、连接状态与 Schema Catalog。
3. 已发布的业务语义模型、指标、维度、关系和术语。
4. 自然语言问数到 SQL Guard、只读执行、Result Oracle、图表和洞察。
5. 查询依据抽屉中的 SQL、口径、数据源、耗时、Oracle 与结果签名，以及危险 SQL 被拒绝。
6. 受控 RAG / 有限 Multi-Agent 的引用、五角色六工具、硬预算和公开阶段 Trace。
7. Verified Answer → Dashboard → Golden Evaluation 的产品闭环。

不在求职视频中展示密钥、本机数据库管理员账号、内部思维过程、生产部署或尚未认证的新版本能力。
